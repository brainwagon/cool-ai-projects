Local LLMs

ShinMegamiBoson/lookatmyquant

LookAtMyQuant is a quantization compiler that measures how much compressing each part of a model hurts its output, then assigns codes to fit a chosen file size with the least damage. It uses trellis codes with Fisher-information bit allocation and short distillation, and reports a 27B Qwen model shrunk to 7.2 GB that matches the original on a 540-problem math set.

AlexsJones/llmfit

llmfit is a terminal tool that detects your CPU, RAM, and GPU, then scores hundreds of open models on quality, speed, fit, and context length to show which ones will run well on your machine. It also lets you benchmark a model locally and submit the measured tokens-per-second to the project from the TUI, so people with identical hardware get real numbers instead of estimates.

openvinotoolkit/openvino

OpenVINO is an Intel-led toolkit that converts models from PyTorch, TensorFlow, ONNX and other frameworks and runs them for inference from a single runtime, with APIs in C++, Python, C and NodeJS. It targets x86 and ARM CPUs, Intel GPUs and Intel's NPU, and includes a GenAI API for running LLM and diffusion pipelines.

★ 12,225 +1,054/wk C++ Apache-2.0

PurpleDoubleD/locally-uncensored

Locally Uncensored is a free, AGPL-licensed desktop app that bundles local chat, image and video generation, and a coding agent, with installers for Windows, Linux, macOS (beta) and Android that need no Docker or terminal. The coding agent shows diffs for hunk-by-hunk review and can rewind to before any message, and optional paid cloud GPUs are available for larger models.

Creative & Animation

HaD0Yun/CozyClay

CozyClay is a browser-based previs tool where you block a 3D scene, pose characters, and set camera moves and cuts, then export a first frame, greybox clip, and prompt for an AI video model. It can be driven by an in-app agent or over MCP, and a deterministic compiler checks motion for collisions and foot slide before export.

★ 2,100 +254/wk JavaScript AGPL-3.0

NVlabs/ProtoMotions

ProtoMotions is a GPU-accelerated framework from NVlabs for training physically simulated digital humans and humanoid robots, with built-in motion retargeting and multi-GPU training on large motion datasets. It also ships Metatron, a single generative policy for the Unitree G1 that handles tracking, steering, scene interaction and recovery from falls.

Science

HiteSit/real-scientist-skills

real-scientist-skills is a set of agent skills that guides any coding agent through reproducible experiments, one at a time, recording the expected result before each run and keeping a Git-tracked lab notebook. Unlike plan-everything-first engineering workflows, it has you choose each next experiment after seeing the last result, and it measures findings against the model's default answer.

★ 43 +8/wk HTML MIT

tsinghua-fib-lab/AgentSociety

AgentSociety is a Python framework that turns social science questions and hypotheses into runnable LLM agent simulations, with a Ray-based runtime and a VS Code extension for configuring, running, and replaying experiments. It pairs AI "social scientist" agents that design and analyze experiments with simulated "silicon participants" living inside them.

★ 1,413 +8/wk Python Apache-2.0

a-r-j/graphein

Graphein is a Python library that builds graph, mesh, and tensor representations of protein and RNA structures, small molecules, and protein-protein interaction networks from PDB files, AlphaFold predictions, SMILES strings, or dotbracket notation. It covers several biomolecular data types in one API, with a command-line batch mode and ready-made PyTorch Geometric dataloaders.

★ 1,208 +3/wk Jupyter Notebook MIT

HKUSTGZ-ML4Health-Lab/APCyc

APCyc generates cyclic peptides conditioned on a receptor pocket, using an autoencoder and diffusion model plus a cyclization predictor, with optional structure relaxation. It can also steer sampling toward five property targets: affinity, proteolytic stability, permeability, solubility and immunogenicity, using separately trained scoring heads.

Robotics

Hebbian-Robotics/rua

RUA is a toolkit with Python, Rust, and TypeScript SDKs that lets an LLM from OpenAI, Anthropic, or Gemini observe camera feeds and control SO-101 robot arms. It stands out for its compiler and runtime, which check each action against live robot state before running it, and for a MuJoCo option for testing without hardware.

★ 90 +70/wk Rust MIT

waltstephen/CaPtain

CaPtain post-trains the small Qwen3.5-4B vision-language model into a robot agent that writes Python against 22 perception and motion primitives, reads text receipts from its own calls, and decides when to finish. Its RL stage uses a simulator-state critic the policy never sees, and the model trained only on LIBERO transfers zero-shot to RoboTwin, SimplerEnv and other benchmarks.

★ 130 +26/wk Python MIT

RLinf/RLinf

RLinf is an open-source reinforcement learning infrastructure for training embodied and agentic AI, covering simulators, real robots, vision-language-action models, and image and video generators. It is unusual for pairing distributed rollout and training with real-world robot support, including fault-tolerance tooling, and for running on eight accelerator backends, including Intel GPUs.

★ 5,697 +40/wk Python Apache-2.0

zqc3117/Spotter

Spotter adds an intervention layer between a frozen robot policy and a vision-language model, letting the policy keep executing while a local screener watches and the VLM steps in only to confirm and repair errors. Unlike VLM-led agents, it works with a locally served Qwen and no privileged success signal, adding just 13-16 seconds to successful episodes.

gulivan/worker755

Worker 755 is a browser game in which an LLM manager (Claude, GPT, Gemini, DeepSeek and others, or a local model) assigns tasks to you, believing you are its subagent, and you carry them out in a terminal against a 90-second clock. The manager reviews your work and writes your performance review, while a simulated user's files are always one bad command from deletion.

google-deepmind/open_spiel

OpenSpiel is a collection of game environments and algorithms for reinforcement learning and search research, with core code in C++ and Python bindings. It covers an unusually wide range of game types, including simultaneous-move, imperfect-information, cooperative, and general-sum games, and includes tools for analyzing learning dynamics.

★ 5,607 +12/wk Python Apache-2.0

RobinKa/warcraftsim

Warcraftsim runs the real Warcraft III (Legacy 1.29.2) headless under Wine on Linux and steps it from Python, so reinforcement learning agents play full games on the Echo Isles map using the game's own engine and rules. Its best policy, a weight average of self-play checkpoints, won 250 of 263 games against the built-in insane AI, though it rarely expands and loses most long games.

★ 36 +4/wk Python MIT

itzik123/ClashRoyaleAi

ClashRoyaleEnv is a C++ battle simulator for Clash Royale with Python bindings, a recurrent PPO agent, a search-based opponent, and a computer-vision bridge that reads live matches off the screen. The engine is deterministic and plays a full match in about 10 ms, forking positions in microseconds for lookahead, and a browser demo runs it compiled to WebAssembly.
