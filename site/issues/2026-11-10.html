Local LLMs

synchopate/llama-modchip

llama-modchip is a set of llama.cpp kernel patches and requantized GGUF files that run mixture-of-experts models, including the 284B DeepSeek-V4-Flash, entirely on CPU with 64 GB of RAM. It squeezes that model to 1.71 bits per weight and uses cache-aware tiling, reporting about 44 tokens/s prefill at 256K context with no GPU.

mw00/project-maya

Project Maya is a local inference engine that runs three very large models (GLM-5.3-Flash, DeepSeek-V4.1-Flash and MiniMax-M3.1-Flash) on NVIDIA or AMD GPUs, with a browser chat and an OpenAI- and Anthropic-compatible API. It spreads each model's experts across GPU memory, RAM and NVMe storage, adjusting as you chat, so models of 300B+ parameters can run on consumer hardware.

ARahim3/DigUp

DigUp is a desktop app for Mac, Windows and Linux that searches your photos, PDFs, documents, recordings, videos and code by describing their content in plain language. It runs Google DeepMind's EmbeddingGemma 2 entirely on-device and jumps to the matching page or moment, while also matching exact strings and working across 100+ languages.

drumih/turbo-fieldfare

TurboFieldfare is a Swift and Metal runtime that runs the 26-billion-parameter Gemma 4 26B-A4B on Apple Silicon Macs, including 8 GB machines, with a Mac app, CLI and local OpenAI-compatible server. It keeps about 2 GB in memory and streams only the needed experts from SSD, reaching 5-6 tokens per second on an M2 MacBook Air.

Creative & Animation

D3voz/openjutsu

Openjutsu is a local Next.js app over a ComfyUI workflow that swaps or edits the main person in a video using a character photo, with modes for multi-person swaps, object removal, and background changes. It runs entirely on open weights (MiniMax H3, SAM 3.1, Qwen3-VL) on your own GPU while preserving the original camera, cuts, motion, and soundtrack.

★ 2,100 +980/wk TypeScript MIT

img2threejs/img2threejs

img2threejs is an agent skill that takes a single reference image of an object or character and writes a TypeScript Three.js factory that rebuilds it from primitives, procedural shaders, and generated geometry, with pivots, sockets, and colliders for animation. It uses no mesh files or photogrammetry, and a quality gate blocks generation until a detail inventory is complete.

★ 21,125 +1,253/wk Python Apache-2.0

FlashML-org/FreeVideo

FreeVideo is a local inference engine that runs the MiniMax H3 video model as a ComfyUI plugin, with launchers for Windows, macOS and Linux. It streams weights between VRAM, RAM and disk and picks precision and attention kernels per GPU, so generation fits in 8 GB of VRAM and 16 GB of RAM.

★ 2,943 +355/wk Python Apache-2.0

edenfunf/reelmimic

ReelMimic analyzes a reference video's shot lengths, transitions, colors, and camera moves, then produces a new 2D animated video in that style from a short brief, running locally through your own Claude Code or Codex account. Several agents build the shots in parallel, and a separate agent reviews each one, with before-and-after screenshots required as proof of every fix.

Science

xuzhougeng/wisp-science

Wisp Science is a local-first desktop workbench where an AI agent runs Python and R, queries about 80 scientific databases through bundled MCP servers, and works on local, WSL, or SSH hosts using your own OpenAI-compatible or Anthropic models. It keeps figures, runs, and decisions in one project, and can freeze manuscript revisions into verifiable Evidence Capsules.

HexaFuture/EmbodiedLab

EmbodiedLab is a benchmark in which a Franka arm in an Isaac Sim physics lab must run its own experiment, reading instruments through three cameras, to find a hidden value across 30 mechanics, circuits, optics, thermal and chemistry tasks. Its parameters are redrawn for every instance, and a run counts only if the result is within tolerance, backed by recorded readings, and the bench is left in the required state.

★ 19 +7/wk Python Apache-2.0

allenai/novelty-eval

This repository provides a benchmark and code for testing LLM-based novelty judges, using OpenReview papers that reviewers unanimously rated as novel or not, paired with ideas from an LLM generator. Its study finds that small prompt changes, such as telling a judge what reviewers concluded, can shift pairwise accuracy by over 50 points.

★ 18 +7/wk Python Apache-2.0

NVIDIA-BioNeMo/BioNeMo-Inference-Runtime

BioNeMo Inference Runtime is an NVIDIA library that runs GPU-accelerated structure prediction for proteins, nucleic acids, and ligands, turning FASTA or MSA input into PDB or mmCIF files with confidence scores. It uses a five-stage pipeline with fused kernels and keeps models as ordinary PyTorch modules, so no TensorRT engine build is needed.

Robotics

dexmal/opendm

OpenDM releases DM0.5, a vision-language-action model for controlling robots from open-ended instructions, along with weights, training and inference scripts, and evaluation workflows. It targets long-horizon tasks, disturbances, and multiple robot embodiments, and the authors report higher scores than Pi0, Pi0.5, and GR00T-N1.7 on simulated benchmarks such as LIBERO and RoboTwin2.0.

★ 2,497 +138/wk Python Apache-2.0

tuotuoLyu/FPO

FPO is the official code for fine-tuning the pi0 vision-language-action robot policy with online PPO-style reinforcement learning, trained on LIBERO and ALOHA Transfer Cube tasks. Because the exact likelihood of a flow-matching policy is intractable, it builds the PPO ratio from per-sample changes in the conditional flow-matching loss, and the paper reports a LIBERO average of 87.2% against 85.5% for pi0-FAST.

★ 131 +76/wk Python MIT

Huy-Quang-Dao/instantTrack

InstantTrack trains a single whole-body motion-tracking policy for the Unitree G1 humanoid across 40 LAFAN1 clips, reaching a normalized return of 0.82 with no failed clips in about three minutes on one RTX 5090. It builds on SuperMimic's differentiable world model and adds GPU-side training optimizations and a contact reward, and the README openly corrects earlier benchmark numbers and flags results that are not yet statistically established.

★ 190 +111/wk Python MIT

groundingpi/GroundingPI

GroundingPI is a 4B-parameter vision-language model that handles detection, referring expressions, pointing, OCR, GUI and layout grounding through one OpenAI-compatible image-and-text API, served with vLLM. Its authors also test it as a perceptual base for robot manipulation and autonomous driving, reporting better data efficiency in controlled evaluations.

Games

THUSI-Lab/GameScaling

GameScaling provides inference code and eight Qwen3.5-based vision-language checkpoints (0.8B to 27B) that read a game frame plus recent history and output the next 200 ms of keyboard and mouse actions. Notably, all models use 1,600 hours of gameplay, comparing Minecraft-only training against a mixed-game set, and the repository includes a vLLM serving script but no training code.

MCG-NJU/AutoTavern

AutoTavern provides TavernGym, a deterministic Rust-based Hearthstone Battlegrounds simulator with Python bindings and a reinforcement learning interface, plus TavernBench, a set of 960 tasks testing combat, positioning and strategy decisions. It covers complete eight-player games under patch 37.0.2 with exact legal action masks, and the benchmark can be scored from released answers using only Python's standard library.

Calix-L/DanKS

DanKS is a Guandan card-game agent that ranks candidate plays by the combinations left in the remaining hand, using an Actor-Critic policy trained with PPO. It also ships two generations of an open-source web game service with a referee and an HTTP interface for connecting your own AI, though trained weights are not included.

★ 831 +72/wk Python Apache-2.0

Jaasssoooonnnnn/FirstLight_CR

FirstLight CR trains Clash Royale agents offline, using imitation learning on 252,238 reconstructed replays followed by PPO self-play, with a native simulation environment that has Python reset/step interfaces. It is unusual in running the game engine itself inside an Android VM, and it ships five checkpoints, including a Hog Cycle specialist the author used to reach Hall of Fame.
