Local LLMs

hyperionaidev/smolmaxxing

smolmaxxing is a patch on llama.cpp that finds the largest language model a small device can run, such as a TV box, an old iPad, or a mid-range phone, and speeds it up with custom kernels and memory tricks. It pages mixture-of-experts weights from flash storage, so a 16B model runs on about 1 GB of RAM and an 80B model on a phone at roughly 3 tokens per second.

huawei-csl/MACaQ

MACaQ is a model-agnostic quantizer that compresses text, image, video and audio models for llama.cpp, vLLM, Diffusers and PyTorch, with 2-4 bit GGUF output for local inference. It reportedly quantizes a 122B-parameter model in 64 minutes using 32.5 GB of device memory, and its MACaQ-R tool refines existing GGUF files while staying compatible with standard llama.cpp.

ollama/ollama

Ollama runs open-weight language models such as Gemma, Qwen, and DeepSeek on your own machine or in the cloud, with a simple CLI, a local REST API, and Python and JavaScript libraries. It also launches coding tools like Claude Code and Codex against local models, and it has a large ecosystem of community-built chat interfaces.

Creative & Animation

Comfy-Org/ComfyUI

ComfyUI is a node-graph interface and backend for building image, video, audio, and 3D generation workflows without code, with a local API for connecting them to other applications. It runs on Windows, Linux, and macOS, and uses asynchronous weight streaming and model offloading so large models can run on GPUs with as little as 4GB of VRAM.

OpenMontageInc/OpenMontage

OpenMontage is a framework that lets an AI coding assistant produce videos from a plain-language request, handling research, scripting, asset generation, editing, and rendering through 12 pipelines and over 100 tools. It can also build finished pieces from real stock footage and open archives rather than animated stills, and its sample films list their generation costs, some under $5.

cth9191/animate

Animate is a Claude Code skill that builds short animated videos entirely in code, rendering a single-file canvas piece to MP4 with a headless browser and ffmpeg. It asks you to approve the story, the look, and a storyboard before animating, and it offers seven built-in styles or a new one matched from your own references.

Papermorph is an agent skill for Claude Code and OpenCode that turns textbook PDFs, stories, and books into narrated, animated lessons, paper-puppet films, documentaries, and explorable pages, all as static web folders. It times the animation to word-level narration, then has the model review its own output with contact sheets and blank-frame checks before fixing problems.

Science

harbor-framework/terminal-bench-science

Terminal-Bench-Science is a benchmark of 96 expert-written tasks drawn from real research workflows in the life, physical, earth, mathematical, and engineering sciences, run against AI agents in a terminal through the Harbor framework. It is built as a community effort in which working scientists propose, build, and review tasks, so the benchmark keeps growing alongside the models it tests.

ScireX is a JAX and Flax library of neural operators (FNO, WNO, GINO and Transolver) for PDE solving and surrogate modelling, with pretrained weights. Its models share one interface and work with jit, vmap and grad, and nine benchmark problems compare them at matched parameter budgets against published results.

DeepXDE is a Python library for physics-informed machine learning that solves forward and inverse differential equations, including fractional and stochastic ones, and learns operators with DeepONet variants. ToolUniverse gives language models a standardized interface to more than 2,700 scientific tools, including machine learning models, datasets, and APIs, and exposes them through an MCP server, a Python SDK, and a `tu` command-line tool. Robotics

CuboiLeo/SuperMimic-Reproduced

SuperMimic-Reproduced is an independent reimplementation of the SuperMimic paper, which trains a humanoid whole-body control policy for the Unitree G1 through a differentiable world model on mjlab and MuJoCo Warp. It was written from the paper alone before the authors' code appeared, and it documents where results diverged: 0.11% failures on the 129k-clip BONES-SEED set, plus drift on long clips.

ArcheOne-AI/RoboScript

RoboScript is an agent framework that lets a frozen foundation model learn a robot manipulation task from one demonstration, rehearse it in a simulator, and store the result as a Task Memory in its context. On RoboTwin 2.0 it reaches 83.4% mean success with no gradient updates, versus 61.7% for a trained policy using 50 demonstrations.

It bundles nine new suites, covering calligraphy, rope tying, catching moving objects, humanoid sports, dexterous hands and safety refusals, alongside tasks from many existing robotics benchmarks.

argonrobotics-ai/alloy

Alloy is a GPU-parallel physics engine for robot learning that simulates rigid robots, cloth, soft bodies, liquids, sand and cables together in one scene, with a CPU fallback. A router assigns each object to a suitable solver (MuJoCo Warp, VBD, MPM or its own DFSPH liquid solver), and the documentation lists known limits openly, including that this 0.x release may change its APIs.
